# NFC 출석 시스템 설치 안내

DB(Supabase `nfc-attendance`)는 이미 만들어져 있고 이 폴더의 파일들과 연결돼 있습니다.

## 1. 교사 계정 만들기 (5분)
1. Supabase 대시보드 → **Authentication → Users → Add user → Create new user**
2. 이메일·비밀번호 입력, **Auto Confirm User** 체크 → 생성
3. **Authentication → Sign In / Providers**에서 **Allow new users to sign up** 끄기
   (외부인이 계정을 직접 만들지 못하게 막음)

## 2. GitHub Pages에 올리기 (10분)
1. github.com → New repository → 이름 예: `attend` → **Public** → Create
2. **Add file → Upload files** → 이 폴더의 `index.html`, `admin.html`, `config.js` 업로드 → Commit
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 주소가 생깁니다: `https://아이디.github.io/attend/`
   - 학생용(스티커): `https://아이디.github.io/attend/index.html`
   - 교사용: `https://아이디.github.io/attend/admin.html`

## 3. 처음 설정
1. `admin.html` 접속 → 1번에서 만든 계정으로 로그인 (처음 로그인한 계정이 관리자)
2. **학생 명단** 탭 → 엑셀에서 학번·이름 두 칸 복사해 붙여넣기 → 저장
3. **등록코드 안내문 인쇄** → 잘라서 학생에게 나눠주기
4. **설정** 탭 → 출석 시간 확인, 필요하면 "지금 위치로"로 학교 위치 등록
5. **설정** 탭 → NFC 스티커에 주소 쓰기 (모든 스티커에 같은 주소)

## 명단 외 추가 등록 (on/off)
- 기본은 **꺼짐**: 명단에 있는 학생만 개인 등록코드로 등록할 수 있습니다.
- 설정 탭에서 켜고 **공통 추가 등록 코드**를 정하면, 명단에 없는 학번도 그 코드로 등록할 수 있습니다.
- 추가로 들어온 학생은 명단에 '추가' 표시가 붙습니다. 확인 뒤 **명단 확정**을 누르거나 삭제하세요.
- 명단에 있는 학번은 켜져 있어도 개인 코드가 필요합니다(공통 코드로 남의 학번 등록 불가).

## 학생 사용법
- 첫날: 스티커에 폰 대기 → 학번·이름·등록코드 입력 → 등록 + 출석
- 다음부터: 대기만 하면 출석 (마감 이후는 자동 지각)

## 자주 생기는 일
- 폰을 바꿨다 / 브라우저 데이터를 지웠다 → 명단 탭에서 **기기 초기화** 후 다시 등록
- 코드를 5번 틀려 잠김 → **코드 재발급**
- 폰을 안 가져옴 → 출석 현황에서 **수동 처리**

## 알아 둘 한계
- 등록한 브라우저(크롬/삼성인터넷 등)를 바꾸면 다시 등록해야 합니다.
- 친구 폰을 빌려 대신 찍는 건 막지만, 학생이 자기 폰을 친구에게 맡기는 건 막을 수 없습니다.
- 위치 확인은 위치 조작 앱까지는 막지 못합니다.
- Supabase 무료 요금제는 **7일간 접속이 없으면 일시정지**됩니다. 방학 뒤에는 대시보드에서 Restore를 눌러 주세요.
