📋 NFC 출석 관리

교사 로그인

Supabase 대시보드 → Authentication → Users에서 만든 계정으로 로그인합니다. 처음 로그인한 계정이 관리자가 됩니다.

반-번호학번이름상태시각기기수동 처리

수동 처리: NFC를 못 찍은 학생(폰 미지참·배터리 등)을 직접 출석/지각/인정 처리하거나 기록을 지울 수 있어요.

기간 내보내기 (엑셀용 CSV)

~

학생별 × 날짜별 상태표로 저장됩니다 (출=출석, 지=지각, 인=인정, 공란=미출석). 기록이 하나도 없는 날(주말 등)은 빠집니다.

명단 붙여넣기

엑셀에서 학번, 이름 두 칸을 복사해 붙여넣으세요 (한 줄에 한 명). 학번이 5자리(예: 30101)면 학년·반·번호를 자동으로 나눕니다.
이미 있는 학번은 이름만 고쳐지고 등록코드·기기 등록은 그대로 유지돼요.

반-번호학번이름등록코드휴대폰관리

휴대폰을 바꿨거나 등록이 꼬인 학생은 기기 초기화 후 다시 등록하게 하세요. 코드를 5번 틀려 잠긴 학생은 코드 재발급으로 풀립니다.

출석 시간

시작 전·종료 후에는 태그해도 기록되지 않아요. 집에서 미리 찍는 걸 막는 데 도움이 됩니다.

학교 위치 확인

공통 NFC 주소는 즐겨찾기해 두면 학교 밖에서도 열 수 있어요. 이 옵션을 켜면 휴대폰 위치로 한 번 더 확인합니다. 학생은 첫 출석 때 위치 권한을 허용해야 해요. (위치 조작 앱까지 막지는 못합니다)

명단 외 추가 등록

꺼져 있으면 명단에 있는 학생만 개인 등록코드로 등록할 수 있어요.
켜면 명단에 없는 학번은 위의 공통 추가 등록 코드로 등록할 수 있어요. 명단에 있는 학번은 계속 개인 코드가 필요해서, 공통 코드로 남의 학번을 가로챌 수는 없어요.
추가로 들어온 학생은 명단에 추가 표시가 붙어요. 확인 후 명단 확정을 누르거나 삭제하세요. 필요한 기간에만 켜 두고 끄는 걸 권해요.

NFC 스티커에 넣을 주소

모든 책상 스티커에 같은 주소를 넣습니다. 아이폰은 무료 앱 NFC Tools → 쓰기 → 레코드 추가 → URL로 기록하세요. NTAG213이면 충분합니다.

교사 계정

먼저 Supabase 대시보드 → Authentication → Users → Add user로 그 선생님 계정을 만든 뒤 여기서 추가하세요.
