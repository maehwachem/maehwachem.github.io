출석 확인 진행

선택한 날짜·반의 출석 대상 기준입니다. 이름 검색과 목록 필터는 위 집계에 영향을 주지 않습니다. 외출·조퇴는 등교 기록과 별도입니다.

먼저 확인할 학생

학생별 출석 현황

반-번호 학번 · 이름 등교 기록 현재 상태 원래 태그 시각 처리

미확인은 아직 확인하지 않은 상태입니다. 결석은 교사가 확정합니다. 조퇴·외출·복귀는 등교 기록과 별도로 남으며, NFC 재태그로 이동 상태가 바뀌지 않습니다. 수동 출석은 태그 시각이 공란입니다.

기간 내보내기

~

출석 대상일과 학생 재적 기간을 기준으로 미확인을 포함합니다. 등교 기록과 이동 상태를 별도 열로 저장합니다.

학생 명단

구글 시트를 명단 원본으로 사용하세요. 학번은 학년도별로 관리하고, 학생 식별자는 진급 때도 유지합니다. 누락된 학생은 자동 삭제되지 않습니다. 새 학년도 명단은 2월 중 미리 적용하세요. 3월 1일부터 해당 학년도 명단이 있어야 출석할 수 있습니다.

명단 붙여넣기 또는 개별 수정

두 열: 학번, 이름. 기존 이름 변경·진급은 시트의 학생 식별자를 유지하세요. 아래 목록의 수정 버튼으로 재적 기간과 상태도 바꿀 수 있습니다.

학번 · 이름 재적 기간 · 상태 등록코드 휴대폰 관리

전출·졸업·비활성 처리 시 마지막 출석 대상일을 종료일로 지정하세요(종료일 포함). 기록은 보존됩니다. 휴대폰 양도·교체 때는 기기 초기화를 사용하세요.

출석 대상일 설정

기본은 월~금 등교, 토·일 제외입니다. 방학·공휴일·재량휴업일은 아래에서 제외해 주세요. 학년별 설정이 전체 설정보다 우선합니다.

지정한 범위의 모든 날에 적용됩니다. 기존 출석 기록은 지워지지 않으며, 대상일에서 빠진 기록은 CSV에 대상 외로 표시됩니다.

출석 시간

시작 전·종료 후에는 태그해도 기록되지 않아요. 집에서 미리 찍는 걸 막는 데 도움이 됩니다.

학교 위치 확인

공통 NFC 주소는 즐겨찾기해 두면 학교 밖에서도 열 수 있어요. 이 옵션을 켜면 휴대폰 위치로 한 번 더 확인합니다. 학생은 첫 출석 때 위치 권한을 허용해야 해요. (위치 조작 앱까지 막지는 못합니다)

명단 외 추가 등록

꺼져 있으면 명단에 있는 학생만 개인 등록코드로 등록할 수 있어요.
켜면 명단에 없는 학번은 위의 공통 추가 등록 코드로 등록할 수 있어요. 명단에 있는 학번은 계속 개인 코드가 필요해서, 공통 코드로 남의 학번을 가로챌 수는 없어요.
추가로 들어온 학생은 명단에 추가 표시가 붙어요. 확인 후 명단 확정에서 출석 시작일을 확인하세요. 잘못된 자가가입은 가입 거절로 학번과 기기 연결을 해제할 수 있습니다. 필요한 기간에만 켜 두고 끄는 걸 권해요.

NFC 스티커에 넣을 주소

모든 책상 스티커에 같은 주소를 넣습니다. 아이폰은 무료 앱 NFC Tools → 쓰기 → 레코드 추가 → URL로 기록하세요. NTAG213이면 충분합니다.

구글 시트 연결

NFC 출석 기록 시트 열기 · 연결 스크립트 받기

명단은 시트에서 편집 → 미리보기 → 적용합니다. 출석·조퇴·외출·복귀 정정은 이 관리 화면에서 합니다. 설치 및 열 안내

이 코드는 지금 한 번만 보여요. 시트의 NFC 출석 → 연결 설정에 붙여넣으세요. 다른 사람에게 보내지 마세요.

시트에서 명단을 보내고, 출석 기록을 시트로 가져올 때 쓰는 코드예요. 새로 만들면 이전 코드는 바로 못 쓰게 되니, 코드가 새어 나갔다고 생각되면 새로 만들어 시트에 다시 넣으세요.
