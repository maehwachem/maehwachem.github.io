# 구글 시트 명단 연결 v2

기존 `NFC 출석 기록` 시트에서 확장 프로그램 → Apps Script를 열고 `Code.gs`를 설치합니다. 기존 스크립트가 있으면 먼저 사본을 보관하세요. 프로젝트 설정에서 매니페스트 표시를 켜고 `appsscript.json`의 범위와 서울 시간대를 적용합니다. 시트를 새로고침한 뒤 **NFC 출석 → 처음 준비 · 연결 설정**을 실행하고 Google 권한 화면을 직접 확인하세요.

교사 웹의 설정에서 만든 연결 코드는 코드 파일이나 시트 셀에 넣지 않고 메뉴 입력창에 넣습니다. Google 사용자 속성에만 저장됩니다. 코드는 명단과 출석을 읽고 명단을 변경할 수 있으므로 학생이나 외부에 공유하지 마세요. 자동 예약은 생성하지 않습니다.

## 명단 열

| 열 | 내용 | 편집 |
|---|---|---|
| A/B | 학번 / 이름 | 교사가 편집 |
| C/D/E | 기존 등록코드 / 기기 / 구분 | 기존 값 보존. 최신 정보는 `서버 명단` 사본에서 확인 |
| F | 메모 | 보존, 서버로 보내지 않음 |
| G | 학생 식별자 | 적용 후 자동. 진급해도 유지. 다른 학생에게 복사 금지 |
| H | 학년도 | 3월~다음 해 2월. 연결 설정과 일치시킴 |
| I | 재적 / 승인 대기 / 비활성 / 전출 / 졸업 | 변경 시 미리보기 |
| J/K | 시작일 / 종료일 | 두 날짜 모두 출석 대상에 포함 |
| L | 명단 버전 | 자동. 웹 변경과 충돌하면 서버 명단 사본과 대조 |

**명단 변경 미리보기 → 동기화 미리보기 탭 확인 → 미리본 명단 적용** 순서입니다. 시트나 서버 명단이 바뀌면 미리보기를 다시 합니다. 누락된 행은 유지되며 삭제되지 않습니다. 전출·졸업은 행을 지우는 대신 상태와 마지막 대상일을 입력합니다. 같은 학번의 이름만 달라졌는데 식별자가 없으면 자동 덮어쓰지 않습니다.

새 학년도 명단은 2월 중 적용하세요. 3월 1일부터 해당 학년도 명단이 없으면 출석할 수 없습니다. 진급할 때 이전 명단을 보관한 뒤 같은 학생의 G열 식별자는 유지하고, A열 새 학번과 H열 새 학년도를 입력합니다. J/K열은 새 학년도 시작일·종료일로 바꾸거나 둘 다 비워 기본 기간(3월 1일~다음 해 2월 말)을 적용하고, L열은 비웁니다. 연결 설정에서도 새 학년도를 선택합니다. 새 학생은 G열을 비워 새 식별자를 발급합니다. 한 번에 한 학년도만 관리합니다. `서버 명단 확인용 사본 받기`는 현재 학년도 기준이며 명단 원본을 덮어쓰지 않습니다.

## 출석·이동 기록

`기간별 출석·이동 가져오기`로 최대 62일을 갱신합니다. 지정 기간을 서버 원본으로 교체하므로 과거 정정도 그 기간을 다시 가져오면 반영됩니다. 그 밖의 기간은 유지합니다. 기존 v1 `출석기록`·`학생별 요약` 탭은 그대로 보존하고 v2 탭에 새 집계를 씁니다.

- `출석기록 v2`: 대상일/미확인/결석 확정 및 등교와 이동 상태 구분.
- `이동기록`: 반복 외출·복귀·조퇴·이동 취소 전체 이력.
- `학생별 요약 v2`: **가져온 기간**의 출석 대상일만 집계. 조퇴일은 출석·지각과 겹칠 수 있으므로 합산해 출석일 수로 사용하지 않습니다.
- 시트의 출석·이동을 편집해도 서버에 보내지지 않습니다. 정정은 교사 웹에서 사유를 남겨 처리하세요.
- 월~금은 기본 출석 대상일입니다. 방학·공휴일·학년별 예외를 웹의 출석 대상일에서 지정해야 집계가 정확합니다.

기존 예약 함수가 있다면 v1의 직접 명단 보내기는 중단하고 새 메뉴를 사용하세요. 기존 예약은 이 스크립트가 자동 삭제하거나 바꾸지 않습니다.

## 검토 후 보완

- 명단 내용·버전 변경은 재확인하지만 학생의 기기 등록이나 코드 입력 실패만으로 명단 적용이 중단되지는 않습니다.
- 승인 대기 → 재적 변경은 J열 시작일을 명시해야 합니다. 승인 전 태그는 시도 기록이며 실제 출석은 교사 화면에서 별도 확인합니다. 간단한 승인은 웹 명단의 명단 확정에서 날짜와 사유를 확인하세요.
- 잘못된 자가가입이 학번을 점유했다면 교사 웹에서 가입 거절 후 다시 미리보기합니다. 거절한 식별자를 새 학생에게 복사하지 마세요. 가입 이력은 보존되고 잘못된 기기 연결은 해제됩니다.
- 전출·졸업의 마지막 대상일과 승인 시작일은 미리보기의 확인 필요 행과 알림에 표시됩니다. 그 날짜가 맞는지 확인한 뒤 적용하세요.
- 한글 이름의 조합 방식(NFC/NFD)은 같은 이름으로 비교합니다.
