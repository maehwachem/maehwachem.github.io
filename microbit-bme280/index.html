실제 마이크로비트 연결과 MakeCode 예제

마이크로비트 v2 · BME280 온도·습도·기압

  1. 전원을 끈 뒤 확장 보드로 SDA → P20, SCL → P19, VCC → 3V, GND → GND를 연결합니다.
  2. 페이지 상단에서 HEX를 내려받고, USB로 연결한 마이크로비트의 MICROBIT 드라이브에 복사합니다. BME280의 주소 0x76과 0x77은 자동으로 확인합니다.
  3. Chrome 또는 Edge에서 실제 기기로 바꾸고, 위치를 선택한 뒤 블루투스 기기 추가 또는 컴퓨터의 USB 기기 추가로 연결합니다. 안드로이드 휴대폰·태블릿은 HTTPS 주소를 Chrome에서 엽니다. 아이폰·아이패드의 기본 Safari는 Web Bluetooth를 지원하지 않습니다.
  4. 기기 카드에서 보드 번호(1~12)를 고르고 번호 보내기를 누릅니다. 보드가 확인한 번호가 LED·기기 카드·그래프 범례에 표시됩니다. 보드의 A 버튼은 현재 번호, B 버튼은 블루투스 기기 코드를 표시합니다. LED에 X가 보이면 센서 배선을 확인합니다.
  5. 약 1초마다 외부 온도(°C), 상대습도(%), 기압(hPa)이 갱신됩니다. CSV에는 측정 당시의 위치 번호와 보드 번호가 각각 기록됩니다.

내장 센서로 연결 시험

  1. MakeCode에서 새 프로젝트를 열고 Bluetooth 확장을 추가합니다. JavaScript 화면에 아래 예제를 붙여 넣고 내려받은 HEX를 마이크로비트에 넣습니다.
  2. 지원되는 컴퓨터용 Chrome 또는 Edge에서 HTML을 브라우저 탭으로 직접 엽니다. 연결 기능을 사용할 수 없으면 아래 로컬 실행 방법으로 엽니다. 블루투스를 켜고 필요한 경우 운영체제의 페어링을 완료합니다.
  3. 실제 기기에서 연결할 위치를 고르고 블루투스 기기 추가로 1대를 선택합니다. 약 1초마다 보드 온도와 상대 밝기가 들어오는지 확인합니다. 연결됨 상태는 UART 구독 상태이고, 수신 중이 실제 데이터가 들어왔다는 뜻입니다.
  4. 연결 해제 후 같은 카드의 다시 연결을 눌러 이름과 기록이 이어지는지 확인합니다. 한 대가 정상일 때 블루투스 기기 추가로 다음 기기를 선택합니다. 처음에는 한 대씩 전원을 켜면 기기 이름을 구분하기 쉽습니다.

MakeCode JavaScript · 내장 센서로 블루투스 먼저 시험

let connected = false
bluetooth.onBluetoothConnected(function () {
    connected = true
})
bluetooth.onBluetoothDisconnected(function () {
    connected = false
})
bluetooth.startUartService()
input.lightLevel()
basic.forever(function () {
    if (connected) {
        bluetooth.uartWriteLine("T=" + input.temperature() + ",L=" + input.lightLevel())
    }
    basic.pause(1000)
})

온도는 보드에서 읽은 값이며 조도는 LED의 상대 밝기(0~255)입니다. CO₂는 외부 센서에서 측정한 ppm 값을 C=620처럼 별도 줄로 보냅니다. 외부 온도는 TA=23.4, lux 출력은 LX=130으로 구분합니다. 센서 모델에 맞는 읽기 코드를 추가해야 합니다. BLE UART는 줄바꿈을 포함한 짧은 ASCII 줄을 권장합니다(전송 단위 최대 20바이트).

USB 직렬 연결 · 기존 MakeCode 예제

// MakeCode JavaScript 예제
// P1 센서값, 내장 온도, 조도를 0.2초마다 HTML로 보냅니다.

serial.redirectToUSB()
serial.setBaudRate(BaudRate.BaudRate115200)

basic.forever(function () {
    let 센서값 = pins.analogReadPin(AnalogPin.P1)
    let 온도 = input.temperature()
    let 조도 = input.lightLevel()

    serial.writeLine(
        "센서값=" + 센서값 +
        ",온도=" + 온도 +
        ",조도=" + 조도
    )

    basic.pause(200)
})

데이터 전송이 가능한 케이블로 연결하고 실제 기기 → USB 기기 추가를 누릅니다(115200 baud). 기존 센서값=523,온도=24.6,조도=120, pulse:523,temp:24.6, 숫자만 있는 줄을 읽습니다. 다른 프로그램에서 직렬 포트를 사용 중이면 닫아 주세요. 새로고침 후 USB 기기를 다시 연결할 때는 카드와 같은 기기의 포트를 직접 선택합니다.

인터넷 없이 열기

받아 둔 HTML을 직접 열면 가상 측정·그래프·CSV 저장을 이용할 수 있습니다. 기기 접근이나 브라우저 자동 저장이 제한되면 HTML이 있는 폴더에서 python -m http.server 8000 --bind 127.0.0.1을 실행하고 http://127.0.0.1:8000/microbit_sensor_dashboard.html을 엽니다. 이 접속에는 인터넷이 필요 없습니다. 처음 MakeCode를 열고 확장을 받거나 온라인 페이지에 접속할 때는 인터넷이 필요할 수 있습니다. 원격 업로드는 추후 별도 연동이 필요합니다.

수집 방식 비교와 저장 기준
수집 방식적합한 상황필요한 조건
블루투스 UART전원만 연결한 여러 모둠을 한 화면에 모을 때Web Bluetooth 지원 환경과 기기별 접근 허가. 동시 연결 수와 안정성은 실제 기기에서 확인.
USB 직렬고정된 자리에서 1대씩 시험하거나 여러 대를 케이블로 모을 때데이터 케이블·USB 포트 또는 허브·Web Serial. 기기마다 직렬 포트 선택.
수집용 마이크로비트 + USB무선 측정 지점이 많고 컴퓨터에는 케이블 하나만 연결하고 싶을 때측정용 보드의 micro:bit Radio 송신과 수집용 보드의 중계 코드가 별도로 필요. 송신기 ID와 유실 확인용 순번을 포함해 USB로 전달하는 방식. 이 시제품에서 중계 모드는 후속 구현 항목.

가상과 실제는 따로 저장합니다. 자동 저장이 가능하면 같은 브라우저와 주소에서 새로고침 후 기록을 다시 볼 수 있습니다. CSV는 모드별 전체 기록을 센서값 한 개당 한 행으로 저장합니다. 기록 한도는 모드당 수신 60,000줄이며 한도에 도달하면 기존 기록을 보존한 채 추가 기록이 멈춥니다. 화면의 시간 범위와 범례 설정은 CSV에 영향을 주지 않습니다. 측정 위치와 번호는 수신 당시 값으로 저장됩니다. 위치 또는 번호가 기록되기 전의 자료는 해당 칸이 비어 있습니다. 기록 충돌을 피하려면 같은 주소에서 대시보드를 한 탭만 열어 사용하세요.
