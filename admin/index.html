글쓰기 편집기 열기 ↗

새 창의 Pages CMS에서 maehwachem 계정으로 로그인합니다. 이미 로그인했다면 글 편집 화면으로 이동합니다.

새 글 올리는 순서

  1. 글쓰기 편집기 열기를 누릅니다. 로그인 후 저장소 목록이 나오면 maehwachem.github.io → main → 글·사진 쓰기를 선택합니다.
  2. 글과 사진 목록에서 항목 추가(Add item)를 누릅니다. 기존 글을 고치려면 해당 제목을 엽니다.
  3. 글 제목·게시일·분류·본문을 입력합니다. 사진은 대표 사진이나 본문에서 추가합니다.
  4. Save를 눌러 저장합니다. 배포가 끝나면 홈페이지의 글·사진에서 확인합니다.

저장 후 홈페이지 반영까지 잠시 걸릴 수 있습니다. 처음 연결하는 경우 아래 안내를 따라 주세요.

01

소개·홈페이지 설정 ↗

소개 상자 제목과 내용, 탐구 소개, 관심 주제와 연락처를 바꿉니다.

02

프로젝트 관리 ↗

프로젝트를 추가하거나 수정합니다. 분류와 순서, 게시일, 대표 이미지와 연결 주소를 정합니다.

03

글·사진 쓰기 ↗

‘항목 추가’로 새 글을 씁니다. 제목과 본문을 작성하고 사진, 링크, 목록 등을 넣습니다. 순서와 게시일 표시도 정합니다.

게시물 위치와 날짜 바꾸기

  1. 프로젝트 관리 또는 글·사진 쓰기를 엽니다.
  2. 홈페이지 표시 순서 → 직접 배치를 선택합니다.
  3. 항목 왼쪽 점 모양 손잡이를 잡고 원하는 위치로 끌어 놓습니다. 위에 있는 항목부터 표시됩니다.
  4. 게시일 (업로드 날짜)을 확인하고 Save를 누릅니다.

날짜순으로 보이게 하려면 ‘최신순’을 선택하세요. ‘홈페이지에 게시일 표시’를 끄면 날짜를 숨길 수 있습니다. 프로젝트는 선택한 카테고리 안에서도 같은 순서로 보입니다. 분류를 옮기려면 해당 항목의 카테고리를 바꾸세요.

처음 한 번만 연결해 주세요

  1. 위 버튼을 누르고 Sign in with GitHub를 선택합니다.
  2. Pages CMS 앱 설치 화면에서 Only select repositories를 선택합니다.
  3. maehwachem.github.io만 선택하고 요청 권한을 확인한 뒤 승인합니다.
  4. 이 저장소의 main을 열고 글·사진 쓰기를 선택합니다.

본인만 사용하려면 GitHub 저장소나 Pages CMS에 다른 편집자·Collaborators를 초대하지 마세요. 이 안내 페이지의 주소를 아는 것만으로 편집 권한을 얻을 수는 없습니다.

수정 후 Save를 누르면 저장되고, GitHub Pages 배포가 끝난 뒤 홈페이지에 반영됩니다. 잠시 기다린 후 ‘홈페이지 보기’에서 확인해 주세요.

이 홈페이지는 공개 저장소를 사용합니다. 저장한 글·사진은 공개되므로 비공개 메모나 학생 개인정보를 저장하는 용도로 사용하지 마세요.
