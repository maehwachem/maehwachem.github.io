소개와 프로젝트를 수정하고, 글과 사진을 올립니다.
편집과 저장은 GitHub 계정으로 로그인한 뒤 사용할 수 있습니다.

로그인하고 편집하기 ↗

Pages CMS에서 maehwachem 계정으로 로그인합니다.

01

소개·홈페이지 설정 ↗

소개 문구, 전공과 활동 배경, 탐구 소개, 관심 주제와 연락처를 바꿉니다.

02

프로젝트 관리 ↗

프로젝트를 추가하거나 수정합니다. 분류와 순서, 설명, 대표 이미지와 연결 주소를 정합니다.

03

글·사진 쓰기 ↗

‘항목 추가’로 새 글을 씁니다. 제목과 본문을 작성하고 사진, 링크, 목록 등을 넣습니다.

처음 한 번만 연결해 주세요

  1. 위 버튼을 누르고 Sign in with GitHub를 선택합니다.
  2. Pages CMS 앱 설치 화면에서 Only select repositories를 선택합니다.
  3. maehwachem.github.io만 선택하고 요청 권한을 확인한 뒤 승인합니다.
  4. 이 저장소의 main을 열면 준비된 세 가지 편집 메뉴가 나타납니다.

본인만 사용하려면 GitHub 저장소나 Pages CMS에 다른 편집자·Collaborators를 초대하지 마세요. 이 안내 페이지의 주소를 아는 것만으로 편집 권한을 얻을 수는 없습니다.

수정 후 Save를 누르면 저장되고, GitHub Pages 배포가 끝난 뒤 홈페이지에 반영됩니다. 잠시 기다린 후 ‘홈페이지 보기’에서 확인해 주세요.

이 홈페이지는 공개 저장소를 사용합니다. 저장한 글·사진은 공개되므로 비공개 메모나 학생 개인정보를 저장하는 용도로 사용하지 마세요.
