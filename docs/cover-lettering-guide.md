# Portfolio cover lettering

Approved master: `assets/uploads/cover-watercolor-sensor-recorder-v2.webp`.

Use the actual master image in every image-edit request. Titles belong inside the watercolor artwork. Use dark navy, thick gently rounded handwritten strokes; avoid formal brush calligraphy, serif/Myeongjo, thin typesetting, and oversized short titles. Keep title height, top-left spacing and weight comparable across covers; reduce only for unusually long titles. Preserve scientific apparatus, transparent burette titrant, waterproof probe, and meaningful connections.

The 20 `cover-series-*-v3.webp` covers were edited with the built-in image tool using the approved master. The sensor recorder, microbit introduction, original equilibrium cover, and three gameplay covers remain retained references.

Rendering must display the full artwork with aspect-ratio 3/2 and object-fit contain. The renderer recognizes `cover-series-` independently of asset version suffixes. Legacy illustrated names also allow `-vN` before `.webp`, preventing the clipping introduced by the motion-analysis v2 filename.

Check the complete contact sheet before replacing assets. Image edits are illustrative; verify scientific objects and colors again. Do not replace integrated lettering with an HTML title overlay.
