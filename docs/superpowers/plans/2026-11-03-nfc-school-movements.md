# NFC 등하교·이동 기록 개선 계획

목표: 등하교 기준시간을 교사에게 명확하게 보여 주고, 학생의 수업 출석과 학교 이동 기록을 분리한다.

보존: 기존 주소·토큰·등교 시각·수업별 기록·교사 정정·취소 이력·위치 제한을 유지한다. 학생 이동 태그는 교사 허가와 구별한다. 하교 기준은 임의로 정하지 않으며 처음에는 미설정으로 둔다.

- [x] DB: settings.departure_time, movements.source와 home 종류, 토큰 소유자 전용 nfc_student_move RPC. 서버 시각·재적·등교·이동 순서·중복·위치 확인. 하교/조퇴 후 수업 태그 차단. 기존 교사 이동 취소 지원.
- [x] 학생 화면: 수업 출석 / 등하교 / 외출·복귀·조퇴 탭. 간결한 카드·상태 배지·기준시간, 실제 저장 전 이동 종류·사유·복귀 예정 확인.
- [x] 교사 화면: 등하교 대시보드 기준시간과 설정 이동, 하교 집계·필터·학생 태그 구분, 설정의 정확한 명칭.
- [ ] 검증: 격리 DB와 UI 회귀 검사(중복·충돌·권한·시각·기록 보존), 휴대폰 폭 브라우저 확인, 소스 검토, 마이그레이션과 GitHub Pages 게시 확인.

파일: attend/index.html, attend/admin.html, attend/admin.js, attend/sessions.js, content/projects.json, supabase/migrations, attend/tests, attend/README.md.


검증 기록: 기존 및 신규 테스트 11/11 통과. 390px 학생 화면, 교사 기준시간 카드와 설정 이동을 브라우저에서 가상 데이터로 확인. 독립 코드 검토 후 설정 캐시·시트 하교 표시·교사 이동 초 단위·연결 실패 후 재입력 문제를 재현 검사로 보완. 운영 데이터 구조 변경 적용 완료(기존 출결 행 수정 없음). 화면 게시 후 최종 응답으로 확인 결과를 보고한다.
