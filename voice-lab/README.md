두 판은 비교를 위해 독립 제작 당시 실행 파일 그대로 보존했습니다. 협업판은 별도 경로로 게시했으며, 실험 세션 복원·A/B 측정·조건 변경 안내를 통합했습니다.

각 폴더의 LICENSE/NOTICE 및 기타 라이선스 파일을 보존합니다. independent-manifest.json은 게시한 독립판 파일의 SHA-256입니다.

2026-11-28 v0.2: 협업판 말하기에 한국어 문장 입력·예문·속도 조절을 연결했습니다. 숫자와 영문은 읽을 소리를 한글로 풀어 써 주세요. 발음·억양은 개선 중이며 두 독립판은 그대로 보존합니다.

2026-11-28 v0.3: 한국어 모음·반모음 길이, 문장 리듬, 끝 억양과 일부 단어 간 받침 연결을 보완했습니다. 한국어의 물리 음성 모델이며 사람 목소리 수준의 자연스러움을 보증하지 않습니다.
