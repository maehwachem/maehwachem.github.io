- 원문: https://www.data.go.kr/data/15084084/openapi.do
- 내려받은 파일: 기상청41_단기예보 조회서비스_오픈API활용가이드_2610.zip
- 격자 파일: 기상청41_단기예보 조회서비스_오픈API활용가이드_격자_위경도(2610).xlsx

- 확인일: 2026-10-23
- 이용조건: 공공누리 제1유형, 출처표시

행정구역코드, 1·2·3단계 행정구역명, 격자 X/Y만 추출했다. 주소 선택 대상이 아닌 이어도 2행을 제외한 3,837행이다. 공식 이름과 좌표를 변경하지 않았다. 전남광주통합특별시의 대기질 API 시도명은 광주 5개 구는 광주, 나머지는 전남에 연결한다. 사용자가 대기질 지역을 별도로 조정할 수 있다.

JSON 열 순서: [행정구역코드, 시도, 시군구, 읍면동, nx, ny]. 기존 저장 설정에 weatherLocation이 없는 경우 기존 대표 좌표를 계속 사용한다. 새로 선택한 지역은 행정구역코드만 브라우저에 저장하며 서버에서 공식 목록의 좌표로 해석한다.
