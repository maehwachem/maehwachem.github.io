# 대기질 측정소 주소 출처

한국환경공단 에어코리아 측정소 정보: https://www.airkorea.or.kr/web/stationInfo?pMENU_NO=93
확인일 2026-10-23. 공개 측정소 정보 화면의 도시대기 532, 국가배경 11, 교외대기 27, 도로변대기 69, 항만 34곳(총 673곳)에서 이름·주소·측정망을 추출했다.

JSON 열: [API 시도명, 측정소명, 시도를 제외한 공식 주소, 측정망]. 실시간 관측값은 여전히 기존 승인된 에어코리아 API로 조회한다. 추가 인증키나 별도의 API 활용신청을 요구하지 않는다.

선택한 시군구와 주소의 첫 행정구역 부분을 비교해 목록을 제한한다. 거리나 임의 좌표로 최근접 측정소라고 단정하지 않는다. 기존 유효한 선택을 우선하고, 같은 읍면동 이름의 측정소 또는 유일한 측정소만 자동 선택한다. 소속을 확인하지 못한 측정소와 다른 지역은 사용자가 '다른 지역 측정소 보기'를 펼칠 때만 선택할 수 있다.
