# KJE의 작업실

- 홈페이지: https://kjelab.kr/
- 글쓰기·관리: https://kjelab.kr/admin/
- 연락처: kjechem@naver.com

## 직접 편집하기

1. 홈페이지 상단 또는 ‘글·사진’ 제목 옆의 **글쓰기**를 누르고, **글쓰기 편집기 열기**에서 GitHub의 `maehwachem` 계정으로 로그인합니다.
2. 최초 한 번 Pages CMS GitHub App을 `maehwachem.github.io` 저장소에만 설치합니다.
3. 이 저장소의 `main` 브랜치를 엽니다.
4. **글·사진 쓰기 → 글과 사진 → 항목 추가(Add item)**에서 새 글을 씁니다. 기존 글을 수정하려면 해당 제목을 엽니다. 소개와 프로젝트는 관리 페이지의 각 메뉴에서 편집합니다.
5. 제목·게시일·분류·본문을 입력하고 Save를 누릅니다. GitHub Pages 배포 완료 후 `kjelab.kr`에 반영됩니다.

프로젝트 목록은 편집기에서 항목을 추가·삭제하거나 순서를 바꿀 수 있습니다. 대표 이미지를 생략하면 기존의 기본 표지를 사용합니다. 링크가 없으면 공개 준비 중으로 표시됩니다.

글·사진 쓰기에서는 항목을 추가하고 제목, 날짜, 분류, 짧은 소개, 대표 사진, 본문을 입력합니다. 본문은 글 편집기를 사용하며 사진과 링크를 넣을 수 있습니다. 글은 기본적으로 직접 배치한 순서로 표시되고, 각 글에 개별 주소가 생깁니다. 고유번호는 편집기가 자동으로 생성합니다.

## 제목·순서·게시일 설정

- 소개·홈페이지 설정 → **소개 상자 제목**에서 제목을 자유롭게 바꿉니다. 기본값은 ‘소개’입니다.
- 프로젝트 관리와 글·사진 쓰기에 각각 **홈페이지 표시 순서**가 있습니다. 기본값인 ‘직접 배치’에서는 목록 항목 왼쪽 점 모양 손잡이를 끌어 순서를 바꾸고 Save를 누릅니다. 각 카테고리에도 이 순서가 반영됩니다.
- ‘최신순’을 고르면 게시일 내림차순으로 표시합니다. 같은 날짜의 항목은 목록 순서를 유지하고, 날짜가 없는 항목은 뒤에 옵니다. 다시 ‘직접 배치’를 선택하면 저장된 목록 순서로 돌아갑니다.
- **게시일 (업로드 날짜)**은 글 목록과 본문, 프로젝트 카드에 표시됩니다. 새 글의 날짜는 편집기의 현재 날짜로 시작합니다. 순서 변경과 본문 수정은 기존 게시일을 바꾸지 않습니다.
- 기존 프로젝트의 정확한 날짜를 모르면 비워 두세요. 추정 날짜를 넣지 않습니다. **홈페이지에 게시일 표시**를 끄면 해당 목록의 날짜를 숨깁니다.
- 분류를 옮기려면 해당 항목의 카테고리를 바꿉니다. 위치와 분류 수정도 로그인한 편집기에서 저장합니다.

## 접근과 공개 범위

공개 홈페이지에는 쓰기 API나 비밀번호·토큰이 없습니다. 편집과 저장은 Pages CMS의 로그인 및 GitHub의 저장소 권한 확인을 거칩니다. 본인만 사용하려면 GitHub 저장소와 Pages CMS에 다른 협업자를 초대하지 마세요. ChatGPT에 연결한 GitHub App과 Pages CMS App은 서로 별개입니다.

저장소가 공개 상태이므로 저장한 내용과 사진, 변경 이력도 공개됩니다. 비공개 초안 보관 기능은 제공하지 않습니다. 글을 삭제해도 Git 변경 이력에는 남을 수 있습니다.

## 파일 구조

- `.pages.yml`: Pages CMS 편집 화면 정의
- `content/site.json`: 소개 제목과 항목, 탐구 소개, 관심과 연락처
- `content/projects.json`: 프로젝트와 링크
- `content/posts.json`: 글·사진 목록과 본문
- `assets/uploads/`: 편집기로 올린 사진
- `assets/content.js`: 공개 콘텐츠 표시, 프로젝트·글 분류, 글 보기
- `admin/index.html`: 관리 시작 화면과 연결 안내

기본 배포는 `main` 루트의 GitHub Pages입니다. 별도 빌드나 데이터베이스가 필요 없습니다. 공개 페이지는 같은 사이트의 JSON을 읽습니다. 프로젝트와 소개를 읽지 못하면 최초 화면을 유지하고, 글을 읽지 못하면 다시 불러오기 안내를 표시합니다. 글 본문은 HTML 허용 목록으로 재구성해 스크립트와 이벤트 속성을 제거합니다.

기존 배터리·센서·면접 도구는 각각의 저장소에서 관리합니다. 이 홈페이지의 편집기는 링크와 소개를 관리하며 도구 자체의 코드를 수정하지 않습니다.

## 짧은 주소

`사이트주소/gas`처럼 짧은 주소로 수업 도구를 엽니다. 목록은 `/links/`에서 보고 복사할 수 있습니다.

- 목록 파일: `content/shortlinks.json` (관리 화면 Pages CMS의 **짧은 주소**에서 고칠 수 있음)
- 동작 방식: 없는 경로로 들어오면 GitHub Pages가 `404.html`을 보여 주고, 이 페이지가 목록에서 첫 경로(key)를 찾아 사이트 안 주소(path)로 옮깁니다. 사이트 밖 주소로는 보내지 않습니다.
- `param`이 있는 항목은 두 번째 경로를 값으로 붙입니다. 예: `/ar/chojigo-nature` → `/science-tools/ar-photo/exhibit.html?ex=chojigo-nature`
- key에는 실제 폴더 이름(`admin`, `assets`, `content`, `links`)이나 다른 저장소 이름(`science-tools`, `interview-note`)을 쓰지 않습니다. 실제 경로가 먼저 열려 짧은 주소가 동작하지 않습니다.

## 하늘 관측실

- 주소: https://kjelab.kr/sky/
- 파일: `sky/index.html`, `sky/style.css`, `sky/app.js`, `sky/core.js`, `sky/worker.js`
- 낮의 태양·달, 밤의 달·행성·밝은 별, 월별 천문력을 제공합니다. 날짜·관측지·시각을 바꿀 수 있으며 모든 시각은 KST입니다.
- Astronomy Engine 2.1.19를 `sky/vendor/`에 포함해 브라우저에서 계산합니다. API 키, 별도 서버, 빌드 과정이 필요하지 않습니다. 별의 좌표와 기준 등급은 IAU 목록을 사용합니다.
- 출몰·위상 시각은 한국천문연구원 자료와 대조했습니다. 일월식은 선택한 장소에서 지평선 위에 있는 구간을 안내하며 날씨나 실제 시야는 반영하지 않습니다. 달의 근·원지점 시각은 근삿값입니다.
- 유성우는 출처를 확인한 날짜만 수록합니다. 현재 2026년 10월 오리온자리 유성우를 포함하며 해마다 자동 반복하지 않습니다.
- 검증: `node --test sky/tests/core.test.cjs`
