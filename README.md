# maehwachem.github.io

과학 교사 maehwachem의 이력과 수업 도구 모음 페이지.

- 이 저장소 이름을 `maehwachem.github.io`로 만들면 https://maehwachem.github.io/ 에서 열린다.
- 수업 도구 자체는 `science-tools` 저장소(https://maehwachem.github.io/science-tools/)에 있다.
- 작업을 추가하거나 공개로 바꿀 때는 `index.html` 아래쪽 `WORKS` 목록에서 한 줄을 고친다.
  - `status:'live'` 바로 열기 · `status:'repo'` 깃허브 저장소 · `status:'soon'` 공개 준비 중
- 노란 칸(`class="fill"`)은 채워 넣을 자리: 이름, 학교명, 경력 기간, 이메일 주소.
