피코를 작업실에 연결하기
MicroPython이 설치된 피코를 데이터 전송용 USB 케이블로 연결해 주세요.
연결하면 피코에서 실행 중인 프로그램을 멈추고 보드 정보를 확인해요. 기존 파일은 변경하지 않아요.
  1. Thonny 등 피코를 사용 중인 다른 프로그램을 닫아요.
  2. 아래 버튼을 눌러 피코의 USB 직렬 포트를 선택해요.


처음 시작하는 피코 작업실
처음 한 번, MicroPython 준비
  1. 피코에 적힌 모델명을 확인하고 아래 공식 페이지에서 해당 모델의 안정 버전 UF2 파일을 받아요.
  2. BOOTSEL 버튼을 누른 채 USB를 연결해요.
  3. 나타난 드라이브에 UF2 파일을 복사해요. 피코가 재시작돼요.
  4. 이 작업실의 피코 연결 버튼을 눌러요. 이후에는 BOOTSEL을 누르지 않고 연결하면 돼요.

연결이 되지 않을 때
PC의 Chrome·Edge에서 별도 창으로 열어 주세요. 충전 전용 케이블, 다른 프로그램의 포트 점유, 학교 PC의 USB 정책을 확인해 주세요. 휴대폰·태블릿에서는 USB 연결이 제한될 수 있어요.
작업과 기록
부품을 고르고 배선을 확인한 뒤 실행해요. 배선을 바꿀 때는 전원을 끄세요. 피코 GPIO에는 3.3V 범위의 신호만 연결해요.
체험 모드는 준비된 예시 값을 보여 줘요. Python 코드를 해석하거나 회로를 시뮬레이션하지 않아요.
실제 피코 하드웨어 연결은 아직 검증 전이에요. 이 버전은 MicroPython 표준 USB 통신에 맞춰 구현했어요.


내 프로젝트
부품별 코드와 설정을 JSON 파일로 보관하고 다시 불러올 수 있어요. 측정값은 ‘CSV 저장’으로 따로 보관해 주세요.
초안은 현재 브라우저에 자동 저장돼요. 브라우저 데이터를 지우거나 다른 기기로 바꾸면 사라질 수 있으니 파일로도 보관하세요.

저장 안내
작업 코드는 이 브라우저의 로컬 저장소에 자동 저장돼요. USB로 받은 측정값은 화면의 메모리에만 유지되며, 새로고침하면 사라져요.
앱에서 코드와 측정값을 별도 서버로 전송하지 않아요. 프로젝트·Python·CSV 파일은 직접 다운로드해 보관해 주세요. 호스팅 서비스의 접속·인증 처리는 별도예요.
체험 데이터는 CSV에서도 ‘demo’로 표시되며 실제 측정값과 구분해요.
